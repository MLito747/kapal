Connect real-time chat · Firebase

GitHub Pages hosts static files, so cross-device comments and playback need an online database. Demo mode works instantly on your own browser, but is not shared with other devices.
  1. Create a free Firebase project at console.firebase.google.com.
  2. In Build → Authentication → Sign-in method, enable Anonymous.
  3. In Build → Realtime Database, create a database and set its rules as shown below.
  4. In Project settings → Your apps, add a Web app and copy its firebaseConfig values into the fields below. Click Save & connect.
  5. Share the room URL. For GitHub Pages, upload this file as index.html.

Configuration is saved in this browser only. For all visitors to auto-connect, edit the DEFAULT_FIREBASE_CONFIG object in this HTML file and upload it to GitHub Pages. Firebase web configuration is public; security comes from database rules, not hiding these keys.

Realtime Database rules

{
 "rules": {
  "rooms": {
   "$room": {
    ".read": "auth != null",
    "comments": {
     ".write": "auth != null",
     "$id": {
      ".validate": "newData.hasChildren(['text','createdAt']) && newData.child('text').isString() && newData.child('text').val().length <= 500 && newData.child('text').val().length > 0 && newData.child('createdAt').isNumber()"
     }
    },
    "video": {".write": "auth != null"}
   }
  }
 }
}

These sample rules are for a public classroom prototype. Any anonymous visitor can write comments or change playback. Use proper admin authentication and rate-limiting before deploying broadly.
